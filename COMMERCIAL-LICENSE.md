# Fabric Commercial Use Policy

Fabric is source-available software, not open source software.

The source code is public so people can inspect it, learn from it, experiment
with it, run it locally, and contribute improvements back to Fabric.

## Allowed

- View and study the source code.
- Fork the repository on GitHub.
- Run Fabric for personal, educational, research, hobby, or other
  noncommercial purposes.
- Modify Fabric for personal or internal noncommercial experiments.
- Submit issues and pull requests.

## Not Allowed Without Written Permission

- Sell Fabric or modified versions of Fabric.
- Offer Fabric as a paid hosted service or SaaS product.
- Build a competing commercial product from Fabric source code.
- Redistribute Fabric source code or binaries as part of another product.
- Remove copyright, license, attribution, or source-available notices.
- Relicense Fabric or any substantial portion of its source code.

## Commercial Permission

Commercial use requires explicit written permission from the copyright holder.

For commercial licensing, partnerships, or private permission, contact Auvexis.
