# Feature: Sidebar Hints

## Task Summary
Add hover hints to sidebar navigation items to provide users with a clear understanding of each feature before clicking.

## Requirements
- [x] Implement a hover detection mechanism on sidebar navigation buttons.
- [x] Display a floating modal to the right of the hovered button.
- [x] The floating modal should contain:
  - An image or GIF at the top demonstrating the feature.
  - A small description text below the image explaining the feature.
- [x] The description area should have `overflow-y: auto` if the text is too long.
- [x] The modal must strictly use existing CSS/Tailwind color variables.
- [x] Ensure smooth entrance and exit animations (e.g., opacity, slide).
- [x] Fully implemented in the frontend.
