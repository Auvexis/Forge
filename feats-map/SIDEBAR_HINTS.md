# Feature: Sidebar Hints

## Task Summary
Add hover hints to sidebar navigation items to provide users with a clear understanding of each feature before clicking.

## Requirements
- [ ] Implement a hover detection mechanism on sidebar navigation buttons.
- [ ] Display a floating modal to the right of the hovered button.
- [ ] The floating modal should contain:
  - An image or GIF at the top demonstrating the feature.
  - A small description text below the image explaining the feature.
- [ ] The description area should have `overflow-y: auto` if the text is too long.
- [ ] The modal must strictly use existing CSS/Tailwind color variables.
- [ ] Ensure smooth entrance and exit animations (e.g., opacity, slide).
- [ ] Fully implemented in the frontend.
