## Done Criteria

- Body inspector appears only after body click.
- Page metadata inspector appears after page selection.
- Block inspector appears after block selection.
- Drag prediction works for new blocks and existing blocks.
- Left and right panels can collapse.
- Left panel remains tree-only.
- Right panel contains blocks plus current inspector.
- Element tree has richer Figma-like functionality.
- Dropdown uses existing app dropdown components.
- Page switcher uses `BaseModal` and page preview cards.
- Add-page button below canvas creates a new page.
- Focused tests, type-check, and build pass.
